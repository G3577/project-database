# Задача: Верстка главной страницы

## Описание

Необходимо выполнить верстку главной страницы веб-сайта в соответствии с предоставленным дизайн-макетом.

## Цели

- Реализовать адаптивный дизайн для различных устройств (десктоп, планшет, мобильный).
- Обеспечить кроссбраузерную совместимость.
- Оптимизировать производительность загрузки страницы.

## Требования

- Использовать HTML5, CSS3, JavaScript.
- Применить методологию БЭМ или аналогичную для организации CSS.
- Интегрировать шрифты и иконки из дизайн-макета.
- Реализовать интерактивные элементы (например, слайдер, выпадающие меню).
- Обеспечить доступность (ARIA-метки, семантический HTML).

## Критерии приемки

- Полное соответствие дизайн-макету.
- Отсутствие ошибок в консоли браузера.
- Скорость загрузки страницы не более 3 секунд (для 3G).
- Корректное отображение на последних версиях Chrome, Firefox, Safari, Edge.

## Зависимости

- Дизайн-макет главной страницы.
- UI-кит (если есть).

## Оценка

- **Время**: 40 часов.
- **Ресурсы**: 1 фронтенд-разработчик.

## Примечания

- Дизайн-макет будет предоставлен в Figma.
- Необходимо использовать React/Vue/Angular (указать конкретный фреймворк).
