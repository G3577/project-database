# Project Database

This repository contains the project documentation and database structure for web development.

## Structure of `docs/` directory

The `docs/` directory is organized into the following subdirectories:

- `01_epics/`: Contains high-level feature descriptions or epics. Each epic describes a significant piece of functionality.
  - Example: `auth.md` (Authorization module epic)
- `02_tasks/`: Contains detailed tasks derived from epics or other requirements. Each task describes a specific unit of work.
  - Example: `task-01-frontend.md` (Frontend layout task)
- `03_specs/`: Contains technical specifications and templates for various aspects of the project.
  - Example: `spec-template.md` (Technical specification template)

Each Markdown file within these directories includes YAML metadata at the top, specifying `type`, `status`, `priority`, and `tags` for better organization and filtering.
